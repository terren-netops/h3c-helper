## Provenance boundary

The project originated from a maintainer-owned assistant workflow and was reorganized into five skills. The detailed historical source fingerprint inventory is retained in the maintainer's private migration record, outside the public distribution. They are not runtime dependencies or a vendor endorsement. Vendor manuals, slides, customer originals and raw assistant exports are not included.

The public source contains maintained workflow guidance, templates and optional offline tools. Parser fixtures are explicitly constructed software-test inputs, not copied manual excerpts or observed device behavior. The migration history does not establish third-party redistribution rights; the project license does not relicense external references.

## Exclusions and future scope

- Five/25-second response promises, fixed benefit percentages, fixed-model topologies and unverified universal rollback commands were excluded.
- Historical service contacts, entitlements and slide screenshots require current applicability checks.
- Referenced H3C_Knowledge_Base.md was unavailable.
- Extend regression cases from real requests with model/Release, source and actual outcomes. Add executable examples only after lab validation.
- Device access, case submission, external integrations and automation remain separate scopes. Preserve the Skills-only architecture for this release.
- The original GPT remains separate. ChatGPT/team distribution requires target-host installation, tool and permission validation; local installation does not establish cross-host availability.

The 2026-09-25 update translates UI, skills, references and templates into English, makes English the default response/output language and retains explicit Chinese handoff headings for compatibility. Technical identifiers, schema semantics and evidence boundaries remain unchanged.
