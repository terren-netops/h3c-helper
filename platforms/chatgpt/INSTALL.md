# ChatGPT Skills

1. Run `python3 tools/build.py --all`; it must exit 0.
2. At chatgpt.com/skills, upload `dist/h3c-helper-chatgpt-<version>.skill` to the personal library only.
3. Open the skill details and confirm the five workflow files, references, templates, schemas and scripts are listed.

The TF-18 upload used an rc.5 archive with this layout; the current package has not been re-uploaded.
