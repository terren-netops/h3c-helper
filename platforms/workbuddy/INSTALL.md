# WorkBuddy

1. Run `python3 tools/build.py --all`; it must exit 0.
2. In WorkBuddy: Skills -> Add skill -> Upload skill, select `dist/h3c-helper-workbuddy-<version>.zip`.
3. Confirm the custom skill h3c-helper is enabled and its version matches `VERSION`; compare `~/.workbuddy/skills/h3c-helper` with `dist/workbuddy/h3c-helper` byte for byte.
