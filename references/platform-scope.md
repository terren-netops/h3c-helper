# Platform scope and capability levels

See plugin.json for the current version. The plugin provides workflows, local parsing and limited constraint checks, not a complete manual collection or prevalidated command database.

| Scope | Available assistance | Required evidence |
|---|---|---|
| H3C switching, routing, security and WLAN | Configuration drafts/reviews, diagnosis, design and compatibility investigation | Exact platform and Release; task-specific manuals |
| Transceivers, cards and AC/AP combinations | Full-model comparison and compatibility evidence | Matching matrices and release notes |
| Servers, storage, cloud and management systems | Official-source research, requirements, comparisons and document explanation | Commands verified for the actual product OS; no assumed Comware syntax |
| Other vendors and mixed networks | H3C interoperability boundaries and requested vendor comparisons | Primary sources for each side; platform labels on commands |
| Service, licensing, warranty and training | Navigation, process explanations, case and course drafts | Current regional rules and contract evidence |

When coverage is insufficient, identify the missing evidence and useful work still possible. Do not invent feature support, hard-code a product list as current recommendations or claim device validation without execution records.
