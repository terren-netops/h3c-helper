# Network design deliverable

Select sections appropriate to the task. Distinguish a requirements sketch from a deployment-ready design.

1. Objectives, business needs, availability, growth, budget and existing constraints.
2. Architecture, alternatives, fault domains and rationale.
3. Capacity inputs/calculations: endpoints/ports, traffic, uplinks, PoE, power, racks, fiber distance and headroom.
4. Device inventory: unique ID, role, model, software, license and evidence status.
5. Port table: device A/port, device B/port, member-link speed, aggregation group, media/distance/modules and VLAN/purpose.
6. Matching physical/logical diagrams: consistent names, addresses, VLAN/VRF, adjacency, business paths and security boundaries.
7. Implementation stages, change scope, rollback conditions and dependencies.
8. Acceptance inputs, methods and expected results for function, failover, capacity/performance, management and security.
9. Operations: monitoring, backups, upgrades, handoff and unresolved risks.
10. Sources and applicable versions for each product/compatibility claim.

Generate structured views from the same network JSON. Check same-VRF address conflicts, port/combo-port use and budgets. Separately report post-failure capacity, shared fault domains, trade-offs and actual visual inspection results.
